# Aether texture credits

All listed source assets are CC0 on Poly Haven. Files are stored locally in `public/aether/textures/`, with no external requests during website use.

- [Rock Boulder Cracked](https://polyhaven.com/a/rock_boulder_cracked): photography by Dimitrios Savva, processing by Dario Barresi. 2K diffuse, 1K OpenGL normal and roughness maps. Used as triplanar/box-projected rock surfaces and tinted stone/ground variants.
- [Kloofendal 48d Partly Cloudy Pure Sky](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky): Greg Zaal and Jarod Guest. 2K HDR panorama used for background and image-based lighting.

The panorama supplies the sky only. Islands, buildings, trees, bridges, crystals and waterfalls remain three-dimensional scene geometry. The user's reference image and the generated design concept are not used as scene background images.
